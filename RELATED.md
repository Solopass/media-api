# Versions and related repos

Every version of this project is kept as a tagged commit (oldest first). Compare versions with `git diff <tag1> <tag2>`; open one with `git checkout <tag>`.

| Tag | Version |
|---|---|
| `v0-yt-local-api-powershell-2026-08-20` | YT-Local-API: PowerShell yt-dlp/ffmpeg download + clip server (Windows) |
| `v1-media-api-wsl-2026-09-10` | media-api: FastAPI + yt-dlp + faster-whisper + summaries (WSL) |

Related: **[vidtranscribe](https://github.com/Solopass/vidtranscribe)**, a separate transcription pipeline (quick-euclid) built between these two versions; possibly an ancestor of media-api's transcription part.
